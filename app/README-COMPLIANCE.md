# COSMOMED - System Zarządzania Zgodnością MDR

System compliance i audytu dla zarządzania zgodnością z rozporządzeniem MDR (Medical Device Regulation 2017/745).

## Funkcjonalności

### Moduł Compliance & Audyt

#### 1. Dashboard Compliance
- Ogólny stan zgodności (%)
- Statystyki: TAK/NIE/ND punktów
- Status 7 głównych obszarów zgodności
- Historia zmian i wersjonowania
- Informacje o ostatnim audycie

#### 2. Checklista MDR
22 punkty kontrolne w 7 obszarach zgodności z pełną funkcjonalnością edycji i monitoringu.

#### 3. Generator Raportów PDF
Generowanie raportów zgodności w formacie PDF.

#### 4. CAPA Manager
System zarządzania działaniami korygującymi i zapobiegawczymi.

## Technologie
- React 18 + TypeScript
- Vite + Tailwind CSS
- jsPDF + html2canvas
- React Router
